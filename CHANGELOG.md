# Changelog

## 0.4.0
- Minimap buttons made with LibDBIcon are hidden by default, since the menu replaces them.
  `/addonmenu minimap show` turns that off; `/addonmenu minimap keep <name>` keeps one.
  Other addons' settings are not changed.

## 0.3.1
- First CurseForge release.
- Project icon.

## 0.3.0
- Flat menu; opt-in "(right click)" rows via `/addonmenu rightclick add <name>` (Bartender by default).
- `/addonmenu launchers` lists launcher names.

## 0.2.x
- Right-click handling experiments; bar tooltip removed.

## 0.1.0
- Initial release: launchers, Addon Compartment entries and slash commands in one Titan menu.
